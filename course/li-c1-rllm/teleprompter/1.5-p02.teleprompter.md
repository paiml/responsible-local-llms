### Beat 1 — talk (106 words)

Dash f takes the file. Dash nt drops timestamps. Dash np drops everything but the results. Then tr turns newlines into spaces. sed trims the trailing space. Each audio file becomes one line in a temp file, merged dot txt. Now the contract. The script counts the lines in the merged file, and the lines with text in them. If either count differs from the number of input files, it stops: contract violated. A file with no speech still writes an empty line. The text count catches it. The script prints contract violated, with the counts, and exits with code 1. The model is never called.
