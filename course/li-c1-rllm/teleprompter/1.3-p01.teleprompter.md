### Beat 1 — talk (105 words)

A model is mostly weights. Each weight is stored in some number of bits. Fewer bits, smaller file. That trade is quantization. Our demo compares three levels. In quantize dot rs: q4_k_m at 4.85 bits per weight, q8_0 at 8.5, f16 at 16. The size formula is one line. Parameters times bits per weight, divided by eight. The result is bytes. Run the lesson three demo. It prints the size of a 0.6 billion parameter model at each level, smallest first. That is an estimate. Check it against the real file on disk. The q4_k_m file is 0.369 GiB, about nine percent over the estimate.
