### Beat 1 — talk (109 words)

Walk the repo. One Cargo workspace. Nine crates. Chapter one uses two: rll-client and ch1-sovereign. rll-client is the one client for all three runtimes. In runtime dot rs, an enum lists apr, Ollama and llama.cpp. Each has a name and a default address. Config reads three variables. RLL_RUNTIME picks the runtime, apr by default. RLL_BASE_URL overrides the address. RLL_MODEL names the model, qwen3-0.6b by default. ch1-sovereign adds a fourth, RLL_LIVE. More in a moment. Watch the switch. Set RLL_RUNTIME to ollama and run the lesson three demo. Same code. Different runtime. Without RLL_LIVE, it replays a stored Ollama reply. Give it a name it does not know, like vllm.
