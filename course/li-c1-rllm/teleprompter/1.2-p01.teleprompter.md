### Beat 1 — talk (108 words)

One model file. Three servers. We take a small Qwen3 model, quantized to q4_k_m, and serve that exact file three ways. First, apr. The script needs one variable: GGUF, the path to the model. It runs apr serve run on that file, on port 8081. Forget the variable and the script stops at once. It tells you to set GGUF. That line is the guard. Second, Ollama. It wants a Modelfile, so the script writes one line: FROM and your path. If ollama list fails, it starts ollama serve. Then it registers the model as qwen3-0.6b. Third, llama.cpp. The script runs llama-server with dash m and your file.
