### Beat 1 — talk (110 words)

Welcome. I'm Noah Gift. In this course you build with generative AI responsibly. The models run on your own machine. Most talk about responsible AI stays abstract. Principles on a slide. Nobody can run a slide. Here, every principle becomes a test. It passes or it fails. Failures start as incentive problems. Code comes second. So we start with incentives. Chapter zero covers seven ideas. Who captures the value. The commons. Game theory. Competition. Externalities. Regulation. Bias loops. These ideas are old. Hardin wrote about the commons in 1968. What changed is speed. A downloaded model copies to any machine you own. Models also act now. An agent calls tools.
