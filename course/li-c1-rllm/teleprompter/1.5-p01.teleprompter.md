### Beat 1 — talk (107 words)

A common job. A folder of recordings, and you want a summary. Speech to text, then text to a model. Two local tools and plain shell. The script is scripts slash whisper-pipeline dot sh. Pass it audio files. With no arguments it prints usage and exits with code 2. Five settings come from the environment. Four set the tools and the server. WHISPER_BIN: the whisper.cpp binary, default whisper-cli. WHISPER_MODEL: the path to a ggml speech model; it has no default. RLL_BASE_URL: the server address, default 127.0.0.1 on port 8081. RLL_MODEL: the model name, default qwen3-0.6b. For each file, the loop runs whisper-cli. Dash m takes the model.
