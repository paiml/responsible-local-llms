The q8_0 file is 0.596 GiB, close. We did not measure why. The 4.85 for q4_k_m is the repo's constant, not a spec. Q8_0 is 8.5 bits, not 8. Here is why. 32 weights as 8-bit values plus one 16-bit scale is 34 bytes. That is 8.5 bits per weight. File size is not memory use. At run time the server also holds a cache sized by the context. Measure the resident memory of the running server. On this GX10, after nine timed requests, with q4_k_m loaded, resident memory is 2.47 GiB on apr, 0.84 on Ollama, 0.69 on llama.cpp.
