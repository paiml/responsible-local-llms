### Beat 1 — talk (102 words)

In the last video the tools lived inside the program. Now they move behind a protocol. MCP, the Model Context Protocol. MCP speaks JSON-RPC. Here, one request line gets one reply line. Three methods matter here: initialize, list the tools, call a tool. Our server is an MCP-style subset. One JSON line at a time, over a socket, inside the same program. Real servers use stdio or HTTP. It binds to 127.0.0.1. Loopback. Your machine only. The client says hello first: initialize. The server names itself. Then the client asks for the tool list. It gets four, each with a JSON schema.
