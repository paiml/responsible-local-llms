### Beat 1 — talk (108 words)

An agent is a model, a loop, and tools. The model never runs anything. It writes text. Your code decides what that text means. There are four tools: add, read file, write file, delete file. Each is a variant of a Rust enum. We ask the model for a JSON tool call. "What is 17 plus 25?" Here is a model answer. I recorded it by hand, ahead of time. It is illustrative. It adds chatter around the call. "Sure." Then the JSON. Then "Hope that helps." Our parser cuts from the first open brace to the last close brace. It reads that span as a typed call.
