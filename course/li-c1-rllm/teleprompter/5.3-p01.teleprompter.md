### Beat 1 — talk (110 words)

Some prompts can leave your machine. Some must not. Sort them in code, then prove the sort. The detector looks for five kinds of sensitive text. An email address. A social-security-shaped number. A card number: thirteen to nineteen digits that pass the Luhn checksum. Health words: patient, diagnosis, prescription. And secrets: password colon, api underscore key, a PEM header. That is all it looks for. It is a heuristic. A name on its own is not one of the five. Do not read it as a privacy product. The rule is short. A sensitive prompt goes local, whatever the policy. A clean prompt goes hosted only if policy allows it.
