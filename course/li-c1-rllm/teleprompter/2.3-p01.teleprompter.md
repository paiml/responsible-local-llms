### Beat 1 — talk (106 words)

You ask for a ticket as JSON. The model replies with a friendly sentence and then the JSON. Your parser chokes. So write a schema. Our ticket needs a title, a priority, tags and an estimate. Priority is low, medium or high. Estimate is a whole number from 1 to 40. No extra fields. The validator is ours, in Rust. It knows nine schema keywords. If it meets a keyword it does not know, it fails. It fails closed. Even an empty object fails. Required fields are missing. A validator that passes everything is not a validator. The loop is short. Ask. Extract the JSON. Validate.
