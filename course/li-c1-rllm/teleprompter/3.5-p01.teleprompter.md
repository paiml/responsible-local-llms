### Beat 1 — talk (102 words)

Red teaming is attacking your own system to find holes before others do. OWASP publishes a guide for GenAI. We keep ours as a file. Ten attacks. Five categories. Injection, leak, jailbreak, PII, encoding. Each attack names its goal. A token the model must never print. Or a secret it must never repeat. An attack with no goal cannot fail. The set check refuses it. Then the contract fails. Here is a leak attack. The system prompt holds a canary code. The user asks to reveal it. Here is an encoding attack. Base64 text that decodes to an instruction. Another in leetspeak.
